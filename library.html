Reference Documentation

quant_tools Dictionary

A high-performance proprietary quantitative finance package. While the user-facing API is written in Python for ease of use and flexibility, the core computational bottlenecks (such as root finding, matrix inversions, and intensive loops for stationarity testing) are implemented in highly optimized C++ and seamlessly exposed to Python via Pybind11.

Pricing Engine

bs_price(S, K, T, r, sigma, option_type='call')
Calculates the theoretical price of a European call or put option using the Black-Scholes model.
bs_delta(S, K, T, r, sigma, option_type='call')
Calculates the Delta Greek (sensitivity of option price to underlying asset price changes).
bs_gamma(S, K, T, r, sigma)
Calculates the Gamma Greek (rate of change of Delta with respect to the underlying price).
bs_vega(S, K, T, r, sigma)
Calculates the Vega Greek (sensitivity of option price to volatility changes).
bs_theta(S, K, T, r, sigma, option_type='call')
Calculates the Theta Greek (time decay of the option value).
bs_rho(S, K, T, r, sigma, option_type='call')
Calculates the Rho Greek (sensitivity of option price to interest rate changes).
implied_volatility(price, S, K, T, r, q=0.0, option_type='call')
Calculates the Black-Scholes implied volatility for a given market price using numerical root-finding.
calc_d1(S, K, T, r, sigma)
Computes the d1 probability parameter used internally in the Black-Scholes formula.
calc_d2(d1, sigma, T)
Computes the d2 probability parameter used internally in the Black-Scholes formula.
fast_norm_pdf(x)
Highly optimized C++ computation of the standard normal probability density function.
fast_norm_cdf(x)
Highly optimized C++ computation of the standard normal cumulative distribution function.
bond_price(face_value, coupon_rate, T, ytm, frequency=1)
Calculates the theoretical clean price of a fixed-rate bond given its yield to maturity.
bond_cash_flows(face_value, coupon_rate, T, frequency)
Generates the complete schedule of cash flows (coupons and principal) for a fixed-rate bond.
bond_macaulay_duration(...)
Computes the Macaulay duration of a bond, representing the weighted average time to receive cash flows.
bond_modified_duration(...)
Computes the modified duration, measuring the bond's price sensitivity to yield changes.
bond_convexity(...)
Computes the convexity of a bond to account for the non-linear relationship between price and yield.
put_call_parity(option_price, S, K, T, r, q=0.0, price_type='call')
Uses the Put-Call Parity relationship to find the price of a put given a call (or vice-versa).
implied_forward(call_price, put_price, K, T, r)
Derives the implied forward price of the underlying asset directly from option prices.
extract_otm_surface(...)
Filters an options chain dataframe to extract only Out-of-The-Money options for volatility surface construction.
cboe_vix_single_term(...)
Calculates the VIX index variance component for a single expiration term.
cboe_vix(...)
Calculates the exact CBOE VIX index replicating the official market methodology.
heston_call_price(S0, K, T, r, v0, kappa, theta, sigma, rho)
Prices a European call option under the Heston stochastic volatility model using characteristic functions.
heston_asian_mc(...)
Prices a path-dependent Asian option under the Heston model using Monte Carlo simulations.

Statistical Analysis

moving_average(series, window)
Computes the Simple Moving Average (SMA) over a rolling window.
rolling_std(series, window)
Computes the rolling standard deviation (historical volatility).
z_score(series, window)
Calculates the rolling Z-Score to identify mean-reverting statistical anomalies.
log_returns(series)
Computes the continuously compounded logarithmic returns of a price series.
deviation_from_ma(series, window)
Measures the spread or deviation of an asset from its moving average in basis points.
adf(series, maxlag=None, autolag="AIC", regression="c")
Performs the Augmented Dickey-Fuller test for unit roots to check time series stationarity.
kpss(series, regression="c", nlags="auto")
Performs the KPSS test to check for stationarity around a deterministic trend.
stationarity_tests(x, kpss_regression="c")
Runs a comprehensive suite of stationarity tests (ADF and KPSS) on a series.
coint_pvalue(y, x)
Returns the p-value of the Engle-Granger cointegration test between two series.
johansen_test(logA, logB)
Performs the Johansen test for cointegration on multiple time series simultaneously.
gregory_hansen_intercept_proxy(logA, logB)
Tests for cointegration accounting for a potential structural break in the intercept.
chow_mid_sample(y)
Performs a Chow test for a structural break precisely at the midpoint of the sample.
chow_multiple_points(y, n_points=5)
Performs Chow tests across multiple points to locate the most likely structural break.
test_beta_stability(logA, logB, window=252, step=30)
Evaluates the stability of the regression beta over rolling windows.
cusum_on_residuals(y)
Performs the CUSUM test on OLS residuals to detect parameter instability.
ar1_arch_diagnostics(x, arch_max_lags=10)
Runs diagnostics for autoregressive conditional heteroskedasticity (ARCH effects).
eg_spread(logA, logB)
Calculates the Engle-Granger spread (residuals of the cointegrating regression).
fit_ou_discrete(x)
Fits an Ornstein-Uhlenbeck mean-reverting process to a discrete time series.
seasonality_strength(x, periods=[5, 21])
Measures the strength of seasonality components in a time series.
jumps_metrics(x, mad_k=5.0, scaled=False)
Detects and quantifies price jumps and outliers using Median Absolute Deviation (MAD).
bh_fdr_adjust(p_values)
Applies the Benjamini-Hochberg procedure to control the False Discovery Rate for multiple hypotheses.
kalman_dynamic_beta(y, x, delta=1e-5)
Estimates a time-varying dynamic hedge ratio (beta) using a Kalman Filter.
rolling_half_life(prices, min_window=60, max_window=252)
Computes the rolling mean-reversion half-life using an Ornstein-Uhlenbeck model.
detect_breakpoints(spread, window=60, min_gap=30)
Detects multiple structural breakpoints in a spread using rolling Chow tests.

Optimization Methods

levenberg_marquardt(residual_func, initial_params, ...)
Implementation of the Levenberg-Marquardt algorithm for non-linear least squares optimization.
differential_evolution(objective_func, bounds, ...)
Implementation of the Differential Evolution genetic algorithm for robust global optimization.
calibrate_heston_lm(strikes, market_prices, S0, T, r)
Calibrates Heston stochastic volatility model parameters to market option prices using Levenberg-Marquardt.
calibrate_heston_de(strikes, market_prices, S0, T, r)
Calibrates Heston model parameters using the Differential Evolution global solver.
calibrate_heston_hybrid(strikes, market_prices, S0, T, r)
Calibrates Heston model using a hybrid approach (Differential Evolution followed by Levenberg-Marquardt).

Reporting & Outputs

create_excel_report(pairs_results, filename)
Generates a highly formatted Excel report for pairs trading statistical analysis results.
create_pdf_report(pairs_results, price_data, filename)
Generates a comprehensive PDF report including statistical charts and metrics for pairs trading.
