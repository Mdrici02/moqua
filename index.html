SABR Calibration

Fit a SABR volatility smile to market prices in one line. Auto-converts prices to implied vols via Jäckel's algorithm.

Heston Model

Full stochastic volatility calibration using a Differential Evolution + Levenberg-Marquardt hybrid optimiser.

Statistical Arbitrage

Cointegration tests (Engle-Granger, Johansen), Kalman filter dynamic beta, ADF/KPSS, and rolling Z-Score.

Quick Start

Start pricing in
3 lines of code

Install via pip, instantiate an engine and get a full Greeks calculator in seconds. No configuration, no boilerplate.

Full Documentation
moqua_example.py
import moqua as mq engine = mq.BlackScholesEngine() pricer = mq.EuropeanOptionPricer(engine) calc = pricer.get_calculator( spot=100.0, K=100.0, T=1.0, r=0.05, sigma=0.20, option_type="call" ) print(f"Price : {calc.price:.4f}") print(f"Delta : {calc.delta:.4f}") print(f"Vega : {calc.vega:.4f}")
