Python Package

Install the moqua quantitative finance library and start pricing in seconds.

Installation

Available on PyPI. Pre-compiled C++ binaries included for Windows.

pip install moqua
import moqua as mq

Quick Start

Pricing a European Call using the Black-Scholes engine.

import moqua as mq engine = mq.BlackScholesEngine() pricer = mq.EuropeanOptionPricer(engine) calc = pricer.get_calculator( spot=100.0, K=100.0, T=1.0, r=0.05, sigma=0.20, option_type="call" ) print(f"Price : {calc.price:.4f}") print(f"Delta : {calc.delta:.4f}") print(f"Gamma : {calc.gamma:.4f}") print(f"Vega : {calc.vega:.4f}") print(f"Theta : {calc.theta:.4f}")

API Reference

Engines
ClassDescription
BlackScholesEngine()Standard Black-Scholes model for equity options (no dividends).
BlackScholesMertonEngine(q)Black-Scholes-Merton with continuous dividend yield q.
Black76Engine()Black-76 model for futures and interest rate options.
BachelierEngine()Normal model — suitable for negative rates / spreads.
Pricers
MethodDescription
EuropeanOptionPricer(engine)Instantiates a pricer bound to a given engine.
.get_calculator(spot, K, T, r, sigma, option_type)Returns a Calculator exposing .price, .delta, .gamma, .vega, .theta, .rho.
StrategyPricer(engine)Pricer for multi-leg option strategies.
PortfolioCalculator(calculators)Aggregates a list of Calculators into a portfolio-level Greeks view.
Statistical Analysis
FunctionDescription
moving_average(series, window)Simple Moving Average over a rolling window.
rolling_std(series, window)Rolling standard deviation (historical volatility).
log_returns(series)Continuously compounded log returns of a price series.
z_score(series, window)Rolling Z-Score for mean-reversion analysis.
adf(series)Augmented Dickey-Fuller stationarity test.
coint_pvalue(x, y)Engle-Granger cointegration p-value between two series.
johansen_test(df)Johansen cointegration test for multivariate systems.
kalman_dynamic_beta(x, y)Kalman filter for dynamic hedge ratio estimation.
