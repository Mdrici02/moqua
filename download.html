Quick Start — Options Pricing

Pricing a European Call using the Black-Scholes engine.

import moqua as mq engine = mq.BlackScholesEngine() pricer = mq.EuropeanOptionPricer(engine) calc = pricer.get_calculator( spot=100.0, K=100.0, T=1.0, r=0.05, sigma=0.20, option_type="call" ) print(f"Price : {calc.price:.4f}") print(f"Delta : {calc.delta:.4f}") print(f"Gamma : {calc.gamma:.4f}") print(f"Vega : {calc.vega:.4f}") print(f"Theta : {calc.theta:.4f}")

Quick Start — SABR Volatility Smile

Calibrating a SABR model and extracting the volatility smile from market prices.

import moqua as mq # Market data: strikes and observed call prices strikes = [80, 90, 100, 110, 120] prices = [23.01, 14.59, 7.97, 4.67, 3.38] # SABRModel auto-calibrates on instantiation # Accepts market_prices directly (converts to implied vols internally) sabr = mq.SABRModel( strikes=strikes, F=100.0, # Forward price T=1.0, # Maturity in years market_prices=prices, option_types=[1.0] * 5 # 1.0 = Call ) print(f"Alpha : {sabr.alpha:.4f}") print(f"Rho : {sabr.rho:.4f}") print(f"Nu : {sabr.nu:.4f}") # Get SABR implied vol for any strike vol = sabr.get_volatility(F=100.0, K=105.0, T=1.0) print(f"SABR vol at K=105 : {vol*100:.2f}%")

API Reference

Engines
ClassDescription
BlackScholesEngine()Standard Black-Scholes model for equity options (no dividends).
BlackScholesMertonEngine(q)Black-Scholes-Merton with continuous dividend yield q.
Black76Engine()Black-76 model for futures and interest rate options.
BachelierEngine()Normal model — suitable for negative rates / spreads.
Pricers
MethodDescription
EuropeanOptionPricer(engine)Instantiates a pricer bound to a given engine.
.get_calculator(spot, K, T, r, sigma, option_type)Returns a Calculator exposing .price, .delta, .gamma, .vega, .theta, .rho.
StrategyPricer(engine)Pricer for multi-leg option strategies.
PortfolioCalculator(calculators)Aggregates a list of Calculators into a portfolio-level Greeks view.
Statistical Analysis
FunctionDescription
moving_average(series, window)Simple Moving Average over a rolling window.
rolling_std(series, window)Rolling standard deviation (historical volatility).
log_returns(series)Continuously compounded log returns of a price series.
z_score(series, window)Rolling Z-Score for mean-reversion analysis.
adf(series)Augmented Dickey-Fuller stationarity test.
coint_pvalue(x, y)Engle-Granger cointegration p-value between two series.
johansen_test(df)Johansen cointegration test for multivariate systems.
kalman_dynamic_beta(x, y)Kalman filter for dynamic hedge ratio estimation.
Stochastic Models
ClassDescription
SABRModel(strikes, F, T, market_prices, option_types, beta)Auto-calibrates the SABR model (Hagan 2002). Accepts raw market prices or implied vols. Exposes .alpha, .rho, .nu and .get_volatility(F, K, T).
HestonModel(strikes, market_prices, S0, T, r)Auto-calibrates the Heston stochastic volatility model using a hybrid Differential Evolution + Levenberg-Marquardt approach. Exposes .v0, .kappa, .theta, .sigma, .rho and .get_price(S0, K, T, r).
Calibration & Optimization
FunctionDescription
differential_evolution(func, bounds, args, pop_size, max_iter)Global optimizer for non-convex calibration problems (e.g. Heston).
implied_volatility(price, F, K, T, option_type)Implied volatility inversion using Peter Jäckel's algorithm (via C++ core). Fast and numerically stable.
Outputs & Visualization
Class / FunctionDescription
PairPlotter(x, y)Visualization tool for spread, beta, and cointegration plots.
create_excel_report(...)Generates a formatted Excel report from pricing or analysis results.
